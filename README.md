# CodeHS Human Typer

A Chrome extension that types code into CodeHS automatically with human-like timing.

## Chrome Web Store

Install CodeHS Human Typer from the Chrome Web Store:

https://chromewebstore.google.com/detail/codehs-human-typer/gonnphhhlabhlggohlipinbjafgjdkic

## Features

* Types code into CodeHS character by character
* Adjustable typing speed
* Designed to behave more like normal human typing
* Helps avoid manually entering large blocks of code
* Simple popup interface
* Works directly with the CodeHS editor

## How It Works

1. Open your CodeHS assignment.
2. Open the CodeHS Human Typer extension.
3. Paste your code into the extension.
4. Choose your typing speed.
5. Start typing.
6. The extension enters the code into CodeHS automatically.
